## 部署

### 提供三种部署方式

为满足不同用户的需求，我们提供三种部署方式：

| 部署方式 | 应用 | MySQL | Redis | 适用场景 |
| --- | --- | --- | --- | --- | --- |
| 全Docker | Docker | Docker | Docker | 新手体验、快速部署 |
| 应用Docker化 | Docker | 外部数据库 | 外部Redis | 正式服务器部署 |
| 完全手动部署 | 直接运行JAR | 外部数据库 | 外部Redis | 开发调试、运维管理 |

> 其中，推荐建议把方式二作为**生产环境**推荐方案。
